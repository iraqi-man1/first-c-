## Tested behavior

- Database persistence across repository reopening, Unicode notes, same-date weight updates, and deleting only the selected record.
- Full backup round trip, merging without removing unrelated records, repeated imports, and rejecting invalid imports without partial writes.
- Numeric validation, week boundaries, gym streaks, and sparse weight history calculations.
- UI interactions for saving a daily check-in, weight, measurements, and a goal.
- Persistent appearance and unit preferences, including pounds-to-kilograms conversion through the weight editor.
- Rendering all ten navigation pages at desktop and 900 × 700 compact sizes, plus light-theme screenshots.
- Local-time rollover across midnight and month boundaries through an injected TimeProvider, without reopening the app.
- Distinct training/rest/missed attendance and partial workout/diet percentages; version 1 backup compatibility without inventing rest days.
- Custom workout routine creation, adding/removing exercises, editing, and independence from daily attendance.
- Album-linked multi-photo insertion, two-image comparison, opening a photo, and zoom changes.
- Arabic preference persistence, RTL navigation, all ten pages in Arabic, and focused input styling.
- Main window configured with full native system decorations and minimum dimensions of 900 × 640; the native caption follows the Fitlog palette where Windows supports caption colors. Embedded logo PNG and multiresolution ICO are present.

Rendered screenshots are generated by Avalonia Headless with the Skia renderer in `artifacts/screenshots/`. All ten desktop pages, compact pages, Arabic pages, and the daily and workout editors were visually inspected. Screenshot data is synthetic and isolated from the user's database. The app starts empty.

## Verification limits

Windows Computer Use reported `Computer Use native pipe is unavailable ... (os error 2)`. Native drag, Snap Layout hover, edge resizing, and operating-system file-picker dialogs could not be automated. The app now uses the native Windows caption and frame for those behaviors; that choice is supported by Avalonia's Windows guidance, but the gestures still need a manual check on a Windows desktop. UI interaction tests use Avalonia Headless. Photo batch persistence used fixture bytes rather than an OS file picker; no personal photos were inserted. macOS and Linux were not tested.
