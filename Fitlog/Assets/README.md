# Fitlog logo

Asset: `fitlog-logo.png`, embedded in the application and used in the sidebar. `fitlog.ico` is generated from it by `scripts/Generate-Icon.ps1` and is used by the executable, native windows, shortcuts, and installer.

Generated using the built-in `image_gen` tool, 2026-09-26. The original PNG is preserved, including its generated alpha channel. No external image service or CLI was used.

Final generation prompt:

> Use case: logo-brand. Asset type: production square app icon for fitlog, a calm dark native fitness tracker. Create one polished minimalist fitness symbol: a bold clean dumbbell whose central negative space subtly suggests an upward progress tick. Centered compact symbol in ice blue #A3C5D5, on a full-bleed solid deep navy #1B2832 square. Flat vector-like graphic rendered as PNG, balanced geometric shapes, strong silhouette legible at 32 px, generous but not excessive margins about 15 percent. No text, no letters, no border, no mockup, no lighting, no shadows, no gradients. Output only the single square icon image.
